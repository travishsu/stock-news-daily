# backtest

## 指令

```bash
uv run scripts/backtest.py [--window N] [--start YYYY-MM-DD] [--end YYYY-MM-DD]
```

| 參數 | 說明 | 預設 |
|------|------|------|
| `--window` | 預測窗口（幾個交易日後驗證） | `1` |
| `--start` | 回測起始日（含） | 最早有報告的日期 |
| `--end` | 回測結束日（含） | 昨天 |

輸出檔案：`reports/backtest_{start}_{end}_T{window}.md`

## 流程

1. 確認使用者的回測範圍：
   - 「上週」→ 推算日期範圍，告知使用者確認
   - 未指定 → 預設用所有現有日報
   - window 未指定 → 預設 1（隔日驗證）

2. 執行指令，等待完成（yfinance 需要網路，稍慢）

3. 讀取輸出的 backtest_*.md，解讀結果：
   - **整體命中率**：>60% 可信，<50% 表示接近隨機
   - **分頻道命中率**：找出哪些頻道的情緒判斷較準
   - **分標的命中率**：列出被頻繁提及且命中率高的標的
   - **情緒偏差**：若偏多/偏空的命中率差異明顯，說明頻道整體偏樂觀或悲觀

4. 回報解讀摘要給使用者（不只是貼報告原文）

## 注意事項

- 回測需要 `reports/YYYY-MM-DD.md` 存在且格式正確（含「市場情緒判斷」、「提及的標的」欄位）
- 台股代碼格式需是 `（4位數字）`，美股需是 `2-5 個大寫英文字母`
- window=1 代表「日報當天情緒 vs 隔日收盤」，適合短線驗證
