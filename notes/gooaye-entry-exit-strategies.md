## 進場策略

### 1. 右側動能為主
> 「絕大多數的東西加碼會發生在右側」

- 等趨勢確立後才加碼，帶動能交易成分
- 不在高點上方追，但確認方向後持續加

### 2. 左側也買，但要有「長黑K」
> 「左側的話，也會買，只是就是要出現一些長黑K」

- 大幅下殺才是左側進場信號，普通回調不接

### 3. 重殺就買
> 「你只要出重殺我就會買」

- 單日出現明顯重殺當天就會小量買入
- 例：2026-03-28 禮拜五出現重殺，小量加倉

### 4. 先寫劇本，按劇本走才加碼
> 「我們前面就先把劇本寫好，然後這些劇本看起來是有按照自己要的方向去演的話，那當然你就可以去選擇是不是要去額外的再做加碼」

- 提前建立基本面論述（如：蘋果中低價 AI 佈局）
- 市場走法吻合劇本 → 確認信號 → 放大倉位

### 5. 走得好就持續加碼
> 「走得好，就一直加碼嘛」

- 強勢股只要持續走強就繼續加（如光通、Marvell、Glass Core 相關）
- 不因部位打得太慢就急追，觀察後再調整

## 出場策略

### 1. 不賣阿呆股，等反彈「人道走廊」再出
> 「我不太願意去在每天一直被割肉的地方，去把東西賣在阿呆股，所以我的做法是，我等到有反彈開人道走廊，那時候我去做減碼」

- 崩跌中不追殺，等反彈後才執行減碼
- 實例：2025 年三四月 Liberation Day 事件，先等反彈，然後四月大跌時有更多子彈抄底

### 2. 弱勢股破底就逐步減
> 「這些弱勢的東西，開始持續出現破底的時候，甚至會慢慢的去做減」

- 主動清理弱勢倉位（如破底的科技股），換取流動性
- 偏好賣弱留強，不是賣強補弱

### 3. 跌破關鍵均線後出場
> 「踩到一些關鍵均線，然後它一樣是在繼續的往下的話，那這個就會變成，我也會把它賣出來」

- 即使均線原本全部向上，一旦跌破關鍵均線且沒有撐住，直接出

### 4. 反彈碰均線但不軋上去 → 準備出場
> 「這個反彈只要碰到上面的均線，然後就有可能會再出一個大根的」

- 判斷是否「真反彈」：有沒有沿均線一路軋上去
- 反彈碰到均線後轉弱 → 視為下一波跌的前兆 → 趁機減碼

## 核心操作邏輯

| 情境 | 動作 |
|------|------|
| 市場重殺 | 小量買入，保留大部分彈藥 |
| 強勢股走強 | 持續加碼（右側） |
| 弱勢股破底 | 逐步減碼，換取流動性 |
| 崩跌中 | 不追殺，等反彈才出 |
| 反彈碰均線但不繼續上 | 減碼，為下一波底部準備資金 |
| 市場如去年三四月型態 | 先減倉騰流動性，等真正大跌再重押 |

> **整體風格**：動能 + 基本面劇本雙驅動；保留流動性優先於追求完整參與；寧賣阿呆進場點，不賣阿呆出場點。
